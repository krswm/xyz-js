# ExtXYZ Molecule Visualizer in JavaScript

## Features

- Visualization of atom positions and force vectors: aimed for MLIP input/output visualization!
- Animation if the ExtXYZ file contains multiple molecule data!
- 3D rendering powered by [Three.js](https://threejs.org)!

## Development

This is a hobby project of mine I started from scratch.

I did not use generative AI for this project.
